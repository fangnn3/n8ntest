This app is a private automation tool built on n8n. It connects to the owner's Google account to read and update Gmail, Google Sheets, Google Drive and Google Calendar data, only to run the owner's own workflows.

Privacy Policy

Privacy Policy

Google user data is accessed only by the account owner's automations and is used solely to perform the workflows they set up.

Data is processed on the owner's private n8n server. It is not sold, shared with third parties, or used for advertising.

Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions.

For questions, use the support contact shown on the Google sign-in screen for this app.
